# SAGD 프레임워크 1000 에폭 소거실험(Ablation) 종합 분석 보고서

## 1. 개요 및 실험 통제 변인

본 보고서는 **통합 SAGD 모델** (모듈 1 SAS + 모듈 2 HDM + 모듈 3 SGA)과 **모듈 1 SAS-Only 모델** (Structure-Aware Serialization 단독 부착) 간의 1000 에폭 소거실험 결과를 비교 분석합니다. 실험 조건의 공정성을 확보하기 위해 모든 실험 변인은 100% 동일하게 통제되었습니다:

- **입력 해상도**: 192 × 192 픽셀 (다운샘플링 없음)
- **토큰 수**: 576 토큰 (24 × 24 공간 해상도)
- **멀티 도메인 배치**: 배치 크기 18 (도메인당 9개 샘플 × 2개 도메인: OpenEDS 2019 + Swirski)
- **총 학습 에폭**: 1000 에폭 (파편화된 로거 기록에서 100% 풀 타임라인 복원 완료)
