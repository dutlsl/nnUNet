2-4. 판정

가설 확인: 연산 병목은 Mamba3가 아니라 CNN. FLOPs 21.4:1, wall time의 61%는 CNN decoder (dec1/2/3 각각 55 GFLOP — 전체 forward의 1/3). Mamba3는 스트리밍 프레임당 +1.85 ms만 기여하고, 현재 모델은 이미 120Hz 실시간 목표(199 FPS)를 충족. → 4단계(경량화)의 annealing 대상 = CNN decoder.

4. 경량화 + Annealing 방안 (개문 조건부)

4-1. Annealing 대상: CNN decoder (bench 판정 기반)

  • 채널 축소 dec1/2/3 (각 55.5 GFLOP → base_channels 32를 decoder만 16으로 채널 ½, decoder FLOPs ¼ ≈ 10.1 GFLOP/레이어 절감)
  • 권중 양자화 W8A16 (decoder conv만 적용; mamba3는 Triton 커널이라 동결) — 3090에서 INT8 conv는 ~2× 속도
  • skip concat 제거 (dec의 cat→conv 대 cat 전 단계의 1×1 conv 압축 — 채널 수 유지하면서 concat 오버헤드 절반)

4-2. RL 보상 유지 방식

  • annealed student S'를 GAZER 최종 policy P*의 KL 스튜던트로 훈련: min KL(S'‖P*) + λ·(1 − reward_teacher(S')) — GRPO의 teacher-likelihood reward를 그대로 objective로 유지 (정적 라벨 피팅 아님)
  • 검증 게이트: annealing 전/후 동일 VAL에서 agreement_teacher 차이가 0.01 미만이면 통과 (0.8962 초과 시 적용 전제)
개문 조건: 3a 동일 지표 비교에서 GAZER ≥ baseline_400. 현재 0.7778 vs 0.8962는 지표가 달라 무효 — 3a 결과 대기.
