Main Process

main.py — ZMQ IPC 백본 구축, Eye/World 프로세스 스폰, EphemeralLogTee로 stdout을 파일 미러링

Eye Process

안구 카메라 프레임 수신 → Detector2DPlugin.detect()로 동공 세그멘테이션 → pupil datum 생성 → ZMQ 발행

World Process

씬 카메라 + pupil datum 수신 → Gazer2D로 시선 매핑 → Accuracy_Visualizer로 정확도 계산

🔌 검출기 플러그인 계층 Detector Plugin Class Hierarchy & Model Routing

Plugin (base class)
  └─ PupilDetectorPlugin (ABC)
       │  detect(frame) → datum
       │  create_pupil_datum()
       │  recent_events(event)
       │
       └─ Detector2DPlugin ← 핵심 통합 검출기
            │
            ├─ active_model = "Mamba3 (T=7)"
            │    → _detect_vivim_mamba_by_t()
            │       └─ VivimBackbone.forward()
            │
            ├─ active_model = "RITnet"
            │    → _detect_ritnet()
            │       └─ DenseNet2D.forward()
            │
            └─ active_model = "2D C++"
                 → detector_2d.detect()
                    └─ C++ 기하학 알고리즘

🧠 Mamba3 (T=3,5,7,9,11)

Vivim-Mamba3 SSM 기반 시계열 동공 세그멘테이션. T개 연속 프레임의 시간적 맥락을 활용하여 세그멘테이션 경계를 안정화.

입력: [1, T, 1, 448, 448] → 출력: [1, 4, 448, 448] (4-class logits)

🔬 RITnet (DenseNet2D)

5-down/4-up U-Net 구조. 단일 프레임 세그멘테이션. 감마 교정(γ=0.8) + CLAHE 전처리 적용.

입력: [1, 1, H, W] → 출력: [1, 4, H, W]

⚙️ 2D C++

Pupil Labs 원본 결정론적 기하학 알고리즘. <1ms 추론, 매 프레임 datum 생성, 프레임 간 지터 극히 적음.

핵심 인사이트: 세그멘테이션 품질 → 타원 피팅 정확도 → norm_pos 정밀도 → Gaze Mapping 입력 품질 → Angular Accuracy. 모든 단계가 직렬로 연결됨.

Confidence의 이중 역할: (1) Gaze Mapping에서 필터 게이트로 사용 (0.6 미만 제거), (2) OpenGL 시각화에서 타원 투명도 결정.

🔧 밸리데이션 파이프라인 버그 수정 히스토리 main 브랜치에서 겪었던 4대 복합 근본 원인과 해결

원인 ① 제너레이터 소진 (Generator Exhaustion)

map_pupil_to_gaze()가 yield 제너레이터를 반환 → closest_matches에서 1회 검색 후 소진

✅ 해결: list(gaze_pos) 명시적 변환 (commit 6a43b3e3)

원인 ② Dispersion 66.7ms 충돌

Mamba3 추론 ~50ms → 실효 15-20fps → |t_gaze - t_ref| > 66.7ms → 매칭 실패

✅ 해결: 점진적 완화 (0.2s → 0.5s → 1.0s → 2.0s) (commit c0454e08)

원인 ③ Saccade Jump Rejection

마커 간 도약 시 confidence=0.0 → min_calibration_confidence(0.6) 미만 자동 제거

✅ 해결: Jump rejection 임계 조정 및 EMA 안정화

원인 ④ Method 문자열 필터 불일치

"2d" in method 필터가 "Mamba3 (T=7)", "RITnet" 등을 탈락시킴

✅ 해결: "3d" not in method.lower()로 반전 (commit 6a43b3e3)

🧪 Part 4 — 4-Case 풀 매트릭스 실험 설계 Threshold × Test Points × Model × Calibration Points = 48 조건

실험 변수 (Independent Variables)

변수 수준
Outlier Threshold 1.2°, 2.0°
Test Points 5p (5개 포인트), 4p (4개 포인트)
Model Mamba3 (T=7), RITnet, 2D C++
Calibration Points 0p (Bypass), 5p, 9p, 12p

측정 지표 (Dependent Variables)

  • 5회 반복 Validation (Val Round 1~5) — 각 Angular Accuracy (°)
  • Mean Accuracy (°) — 5회 평균
  • Peak Accuracy (°) — 최솟값 (= 최고 성능)
  • Std Dev (°) — 안정성 지표
  • Mean Precision (°) — RMS 연속 안정성

4가지 실험 Case 정의

Case Threshold Test Points 특성
Case 1 1.2° 5p 엄격 임계 + 다포인트
Case 2 2.0° 5p 완화 임계 + 다포인트
Case 3 2.0° 4p 완화 임계 + 소포인트
Case 4 1.2° 4p 엄격 임계 + 소포인트

캘리브레이션 포인트 설정

  • 0p — 캘리브레이션 Bypass (raw pupil→gaze)
  • 5p — 5-point 캘리브레이션
  • 9p — 9-point 3×3 Grid (기본 설정)

💡 핵심 인사이트 & 분석 결론 실험 결과에서 도출된 주요 발견사항

1. 세그멘테이션 품질 ≠ Gaze Accuracy

Mamba3의 체감 마스크 품질이 2D C++보다 열위에도 Gaze Accuracy는 유사하거나 우수함. LinearRegression이 체계적 편향(Systematic Bias)을 자동 보정하기 때문.

→ 최종 오차의 직접 원인은 프레임 간 무작위 지터(Random Jitter)뿐

2. 2D C++가 딥러닝을 압도하는 이유

결정론적 기하학 알고리즘 → 프레임 간 지터 극히 적음 → Precision 최우수. 반면 딥러닝 모델은 확률적 마스크 변동으로 인한 지터가 오차 하한선을 형성.

3. 캘리브레이션 포인트 수의 비선형 효과

12p가 항상 9p보다 좋은 것은 아님. Case별로 최적 캘리브레이션 포인트가 다름 → 과적합과 일반화의 트레이드오프.

4. Mamba3의 양면성

최고 Peak (0.447°)를 달성하지만, 동시에 전체 Fail (Case 4 12p)도 기록. 시계열 맥락의 하이리스크 하이리턴 특성.

5. RITnet의 안정성 우위

4개 Case 중 3개에서 Best Mean 달성. Fail 빈도 최저. Precision 일관적으로 ~0.104°. 프로덕션 환경에 가장 적합.

6. Outlier Threshold의 양날의 검

1.2°: 엄격하여 고정밀 결과를 산출하지만 Fail 위험 증가.
2.0°: 안정적이지만 큰 오차 포인트가 포함되어 Mean 상승.
